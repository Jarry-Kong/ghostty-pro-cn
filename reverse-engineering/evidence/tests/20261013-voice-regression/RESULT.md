## 变更

修复应用历史限额后未立即刷新占用空间的问题。清理结果写回列表后，现同步重新统计恢复版录音目录大小；不读取或修改原版录音。

修复播放原版录音时右侧稿件仍显示上一条内容的问题。现在按实际加载的音频顺序和时长生成稿件时间线，可跟随当前分段高亮；新合成朗读复用同一时间线逻辑。

修复右键读取“Claude 最新回复”期间切换标签／分屏仍可能播放旧终端内容的竞态；异步读取完成时必须仍是当前聚焦 surface 才继续朗读。

新增原版录音的显式“导入副本”流程：用户逐条确认后复制音频和稿件到恢复版目录，保留日期、摘要、项目、终端和改写标记；以原记录 ID 幂等去重，原目录保持只读。恢复版索引新增可选 `originalSourceID`，旧索引无需迁移。

重复导入现会核对同一原记录 ID 的日期、摘要和完整稿件；内容冲突时明确拒绝，不再静默当作已导入，原索引和原文件保持不变。

导入后按创建时间稳定排序；已有记录时间相同时保持原顺序，避免迁移一条旧录音扰动无关历史。
