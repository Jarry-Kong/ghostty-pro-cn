# 系统语音真实播放检查

> 创建于 2026-10-13 · 最后更新 2026-10-13

功能：VOICE-02、VOICE-04；关联 T-025、T-028 的部分步骤。

使用固定句子“你好，这是合成测试，不包含私人内容”调用 `SystemSpeechRenderer`，在内存生成 WAV，核对帧数、时长和 `AVAudioPlayer` 解码结果后实际播放至结束；再验证预先取消的第二个合成任务不返回音频。编译和运行退出码均为 0，无警告。

本批不读取 Claude 会话、不保存音频、不联网。它证明当前机器的系统合成与原生播放通路可用，但没有通过恢复版菜单触发，也不证明选区内容、暂停／继续／倍速／拖动、跨片段、人工听感和原包 UI 已验收。
