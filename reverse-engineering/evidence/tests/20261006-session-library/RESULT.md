## 原包依据与开发

依据 [真实窗口记录](../../behavior/20261006-original-ui.md) 和 [二进制规则](../../behavior/20261006-session-rules.md) 重建搜索、筛选、全选／清空、日期分组、底部帮助／关闭／批量按钮及四种模式。

名称不再使用问题预览；读取 JSONL 的自定义／模型名称，按原包回退读取会话目录的 `custom-title.json`。名称侧文件只读，损坏时回退，不迁移或改名。未命名显示原包文案，日期按 `MM-dd HH:mm`，目录按用户主目录缩写。

运行检测使用本用户进程的可执行路径与有限参数，不解析环境变量，不记录完整参数。支持已识别原生／官方 Node 客户端的 UUID 恢复参数；以父进程关系区分本应用与外部客户端。无法定位编号的候选客户端保留不确定状态。窗口引用仅用于切换，不作为进程活跃证据。

增加了编号首字符／元字符保护、文件 UUID 与记录编号一致性检查、非法恢复命令禁止拷贝、目录别名匹配和整批预检查。仍有未观察到启动成功时需要关闭启动窗口重试的边界；无编号新会话完整定位尚未恢复。
