# 网关设置、发送确认与控制器接入

创建于 2026-10-06 · 最后更新 2026-10-06

## 当前产品行为

- 远程模式可填写网关基础地址、模型、原包四项声音或自定义编号；地址与模型作为可选字段保存，旧恢复设置仍可读取。
- 访问令牌只在 VoiceController 内存字段存放，使用 SecureField，不编码进 VoiceSettings，不读原版偏好或钥匙串。退出后需重填；钥匙串和环境导入尚未恢复，不能称为凭据功能全部完成。
- 朗读前校验地址／令牌，并显示目的 URL 与全部清洗后的文字供用户确认；默认回车为取消，没有自动发送许可。代理没有填凭据或点击发送。允许同一主机的音频 GET，不携带网关令牌；外部音频主机和自动重定向在此入口仍拒绝，待具体授权流程。
- 同一批次固定捕获地址／模型／声音／令牌快照，逐段调用客户端，复用现有取消、播放及录音许可。缺配置或远程错误当前明确报错；原包“本次系统音色回退而不改变设置”尚未接入。
- 录音按内容头识别 wav／mp3／m4a，未知音频为 audio，不再统一写成 wav；历史加载保留 basename／前缀／类型白名单和其他安全检查。真实 MP3／M4A 存取仍待验证，不把头部分类检查当作格式有效性证明。
- 远程片段 frameCount=0 表示未取得精确帧数；分段与播放使用原生解码实际时长，不由该值推算。系统合成与从文件读取仍保留真实帧数。

## 验证与限制

旧配置、目录、自定义编号、地址／模型往返及设置编码无 token 字段检查实际通过；应用构建通过 /tmp/ghostty-gateway-controller-build.log。WAV／MP3／M4A／未知头部分类和既有真实 WAV Base64／暂停定位检查实际通过。真实 WAV 历史保存、读取、回收站及找回回归使用隔离临时数据（/tmp/ghostty-gateway-history-check.log）。

发送确认窗口仅代码／构建检查，未实际发送；没有凭据、真实目的地址和具体测试文字授权，因此真实服务验收未完成。完整设置原版布局、钥匙串、环境导入、外部音频主机确认、重定向、系统回退、流式播放与全部验收仍待完成。
