# 改写设置、朗读流程与历史标记接入

创建于 2026-10-06 · 最后更新 2026-10-06

## 当前接线

- 改写默认关闭；设置可选保守／自然、正整数最小字数、原包模型或自定义编号。触发判断为原文 Swift 字符数达到阈值且不超过 8000；历史准备稿不再重新调用模型。
- 可共享语音网关或使用独立改写地址／内存令牌。独立令牌的用户明确保存／读取入口复用原生钥匙串，采用不同 service 和消息端点 account；没有代理实际产品凭据读写或网络请求。独立网关开关缺省 false 的原包初始化对照仍未完全核实。
- 控制器按捕获的配置快照先确认改写原文，再请求模型；成功后清洗／分段，空结果／错误／未配置保留最初规则清洗稿。网络取消和任务代际变化不继续合成或回退。
- 改写后才显示语音发送确认，展示真正要合成的文字，两个目的地址分别授权。取消不发送本步请求；提示明确已发送的改写不能撤回。模型提示词字节一致不等于事实保留保证，界面提醒核对。
- UI 独立显示正在改写、失败原因及系统音色回退；停止清除旧提示，防止历史重播误显示上一批次状态。
- 新录音元数据可选 wasRewritten，旧记录缺字段兼容，音频及 record.json 保留标记。重播已录音频不调用模型，标记仅说明稿件来源，不表示模型事实已验证。

## 实际验证范围

VoiceSettings 独立检查通过改写字段／独立网关往返、旧配置、非法独立地址不持久化且其他地址保持；真实 WAV 临时历史检查通过标记保存与读取、旧记录缺字段、既有回收站／找回／锁与数据保护，测试文件已清理（/tmp/ghostty-rewrite-history-check.log）。最终设置／控制器／元数据／阶段显示构建通过 /tmp/ghostty-rewrite-integration-build.log。
